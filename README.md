# UNO Online

A professional online multiplayer UNO website built with React, Node.js, Express, Socket.IO, and TypeScript.

## Quick Start

1. Install dependencies from the root directory:
   \`\`\`bash
   npm install
   \`\`\`

2. Start both frontend and backend development servers concurrently:
   \`\`\`bash
   npm run dev
   \`\`\`
